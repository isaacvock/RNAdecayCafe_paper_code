# RNAdecayCafe_paper_code

This repository contains the R scripts used to reproduce the figures in the *RNAdecayCafe* manuscript.

## Directory Structure

- **[`Final/`](Final/)**: Contains the updated, polished set of scripts to reproduce all main figures (**Figures 1–2**) and supplemental figures (**Supplemental Figures 1–10**) in the final published version of the manuscript (*Genome Research*). All required input datasets for these scripts are hosted on Zenodo at [https://zenodo.org/records/23984975](https://zenodo.org/records/23984975). See [`Final/README.md`](Final/README.md) for a full overview of the scripts, input files, and R package dependencies.
- **[`bioRxiv_version/`](bioRxiv_version/)**: Contains the older set of scripts used to reproduce the figures in the original bioRxiv preprint. See [`bioRxiv_version/README.md`](bioRxiv_version/README.md) for details on the preprint scripts and data links.
